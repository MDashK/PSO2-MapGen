# Area names for the PSO2 map tool.
#
# One line per ModelId.  The separator can be "=", ":", "-", a comma, a tab or just spaces,
# and "#" or "//" start a comment.  An id that is not listed here simply shows its number,
# and deleting this file changes nothing but the labels.
#
#   330 = Ruins
#   311 : Forest 1
#   310   Forest 2
#
# THE NAME IS ONLY A LABEL.  What the tool reads, generates and exports is always the number,
# so renaming anything here cannot change a map or a block.json.
#
# The list below was derived from the 583 quest packets, not from the game's own text: for each
# model it takes the area folder the packets live in, and the zone it sits at inside a free
# exploration.  The zone order is what gives the 1 / 2 / 3, and the areas marked "(fixed map)"
# are the ones that are always unkB = 0 - the last zone of an exploration, which is not
# generated at all but shipped as a .lat.  Correct anything that looks wrong; it is yours.
